# Puerta 2 — Checklist manual (T2.11)

Checklist para que Pedro ejecute la **puerta 2** en macOS (también válida en Linux). Cubre los criterios de aceptación de la fase 2 del visor de solo lectura y de la importación/exportación Markdown en CLI.

Los resultados de la semana de uso (notas, incidencias, métricas) se registran en `docs/gates/fase-2.md`. Esta guía solo describe **qué comprobar** y **cómo**.

## Antes de empezar

- [ ] Node **≥ 22.18** y dependencias instaladas (`pnpm install` en la raíz del repo).
- [ ] Visor web compilado: `pnpm build:web` (necesario para abrir la shell en el navegador; el script `--check` de CI no lo exige).
- [ ] Binario CLI disponible: `pnpm exec gaveta version`.
- [ ] Ejecutar el preparador (no toca tu vault real):

  ```bash
  ./scripts/gate-t2.11.sh
  ```

  **Resultado esperado:** se crea un vault temporal (por defecto `$TMPDIR/gaveta-gate-t2.11`), se importan notas de `fixtures/markdown`, se arranca `gaveta serve` en segundo plano, se imprime una URL con `?token=…` y al final se añade un párrafo a la nota **Recarga en vivo** (`importados/demo/recarga-en-vivo.html`) para probar la recarga en vivo.

- [ ] Abrir en el navegador la URL completa que imprime el script (incluye `?token=`). **Resultado esperado:** carga la shell de Gaveta sin pedir credenciales adicionales.

> Variable opcional: `GAVETA_GATE_VAULT=/ruta/custom` cambia la carpeta del vault de demo.

## 1. Servidor local (`gaveta serve`) — T2.1, REQ-CLI-12, REQ-SEC-06

- [ ] Comprobar que el proceso escucha solo en loopback:

  ```bash
  lsof -nP -iTCP -sTCP:LISTEN | grep gaveta || lsof -nP -iTCP:3847 -sTCP:LISTEN
  ```

  **Resultado esperado:** dirección `127.0.0.1` (no `0.0.0.0` ni `*`).

- [ ] Sin token, la API rechaza la petición:

  ```bash
  curl -s -o /dev/null -w '%{http_code}\n' "http://127.0.0.1:<puerto>/api/notes"
  ```

  **Resultado esperado:** `401`.

- [ ] Con token y origen correcto, la API responde:

  ```bash
  curl -s -H "x-gaveta-token: <token>" -H "Origin: http://127.0.0.1:<puerto>" \
    "http://127.0.0.1:<puerto>/api/notes" | head
  ```

  **Resultado esperado:** JSON con `ok: true` y lista de notas.

- [ ] `Host: localhost` debe fallar (REQ-SEC-06):

  ```bash
  curl -s -o /dev/null -w '%{http_code}\n' \
    -H "Host: localhost:<puerto>" -H "x-gaveta-token: <token>" \
    "http://127.0.0.1:<puerto>/api/notes"
  ```

  **Resultado esperado:** `403`.

## 10. Importar y exportar Markdown — T2.17, REQ-MIG-01–11

- [ ] Importación adicional en seco:

  ```bash

  ```

  **Resultado esperado:** plan sin escribir archivos; `ok: true`.

### Exportación e ida/vuelta

- [ ] Exportar una nota importada:

  ```bash
  EXPORT_DIR="$(mktemp -d)"
  GAVETA_VAULT="$TMPDIR/gaveta-gate-t2.11" pnpm exec gaveta export importados/tareas/tareas-basicas --to md --out "$EXPORT_DIR" --json
  ls "$EXPORT_DIR"
  ```

  **Resultado esperado:** archivo `.md` con front matter y tareas en GFM.

- [ ] Reimportar en subcarpeta nueva:

  ```bash
  GAVETA_VAULT="$TMPDIR/gaveta-gate-t2.11" pnpm exec gaveta import "$EXPORT_DIR" --in importados/reimport --on-conflict rename --json
  ```

  **Resultado esperado:** nueva nota HTML válida; `gaveta doctor --json` sin enlaces rotos nuevos entre las notas importadas.
