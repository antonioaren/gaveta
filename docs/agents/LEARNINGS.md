# Agent learnings

Short log of pitfalls found while implementing tasks. Read this before starting a task. Append one line when you hit something the next agent would otherwise repeat. Do not delete earlier lines.

Format: `YYYY-MM-DD · T<id> · what went wrong · how it was fixed`

- 2026-10-22 · T0.3 · The VM snapshot can lag `origin/main` (T0.2 was already merged). · `git fetch origin main` before treating a merged task as missing.
- 2026-10-22 · T1.1 · h4–h6 are allowed "con aviso" but the catalog has no `W_*` for them. · Set `headingWarning` on the element and do not invent a code.
- 2026-10-22 · T1.1 · `packages/core` sets `types: []`, and the root tsconfig omits `noUncheckedIndexedAccess`. · Keep core tests free of `node:fs`; a `!== undefined` guard that core needs fails `no-unnecessary-condition` under `tests/`.
- 2026-10-22 · T1.6 · `types: []` types `node:fs` as an error, including in a package that only imports `@gaveta/core` (server). · Set `compilerOptions.types` to `["node"]` and depend on `@types/node` in core and in those packages, matching the CLI.
- 2026-10-22 · T1.6 · `path.normalize` collapses `..` before symlink resolution, so `link/../x` looks inside when `link` points outside; macOS `/tmp` is itself a symlink, so rejecting every not-yet-inside symlink target false-rejects absolute paths. · Walk one segment at a time and reject an escaping symlink or `..` only after the walk has entered the vault.
- 2026-10-22 · T0.4 · Vitest's include list does not cover `fixtures/`, so tests in that package never run under `pnpm test`. · Add `fixtures/src/**/*.test.ts` to `vitest.config.ts`.
- 2026-10-22 · T0.4 · Prettier printWidth 100 wraps `[[Title with spaces]]` onto the next line and splits the wikilink. · Put each wikilink in its own short paragraph.
- 2026-10-22 · T0.4 · Prettier puts the closing `>` of a long `</a>` on the next line, so a `</a>` regex misses the anchor. · Match `</a\s*>` when reading fixture HTML.
- 2026-10-22 · T0.4 · CodeQL treats fixture HTML as library input: `.replace(/<[^>]+>/g)` is incomplete sanitization, and `/\[\[[^\]\r\n]+\]\]/g` is polynomial ReDoS. · Scan for tags and `[[…]]` with `indexOf` instead of those regexes.
- 2026-10-22 · T1.3 · A recursive contract walk overflows on the depth fixture; `parseNote` already scans unsafe content iteratively and does not apply the allow-list. · Walk with an explicit stack, stop descending past `MAX_NOTE_DEPTH`, and keep the parser diagnostics for anything buried deeper.
- 2026-10-22 · T1.3 · `srcset` is not an allowed attribute, and `W_REL_UNKNOWN` keeps that code when `rel.strict` is on. · Report `E_HTML_INVALID` plus `W_REMOTE_RESOURCE` for a remote srcset; upgrade only the diagnostic severity under strict rel.
- 2026-10-22 · T1.2 · parse5 defaults `scriptingEnabled` to true (a script inside `<noscript>` stays text) and a leading U+FEFF is reported as `missing-doctype`. · Parse with `scriptingEnabled: false` and strip one leading BOM.
- 2026-10-22 · T1.13 · Commander consumes the next token as the value of `--from`, so `--from --json` stores `"--json"` and never sets the flag (`--from -` itself does work). The bin imports `.ts` with no emit. · Reject a `--from` value that starts with `-` other than exactly `-`. Re-exec with `--experimental-strip-types` only when `process.features.typescript` is off; Node 22.18+ strips types by default and e2e that spawn `node bin/gaveta.js` never see the shebang.
- 2026-10-22 · T1.5 · Prettier `singleQuote` rewrites CSS attribute quotes, and fixture vaults must stay byte-identical to `packages/core/src/theme/theme.css`. Playwright stays on T1.25: CI does not install a browser. · Match either quote in theme tests, copy the stylesheet into each `fixtures/vaults/*/.gaveta/theme.css`, and leave the `file://` click-through to T1.25.
- 2026-10-22 · T1.5 · The NFR generator fingerprint includes `vaults/empty/.gaveta/theme.css`. · Update `GOLDEN` in `fixtures/src/generate.test.ts` when that file changes.
- 2026-10-22 · T1.7 · `node:sqlite` is unflagged only on Node ≥ 22.13 and still prints `ExperimentalWarning` through `process.emit('warning')` the first time `DatabaseSync` is constructed, which pollutes CLI `--json` stderr. · Engines are `>=22.13.0`. Swallow that one warning in `process.emit` before opening a database; leave every other warning alone.
- 2026-10-22 · T1.7 · Node's type stripper (what `node bin/gaveta.js` uses on 22.18+) rejects constructor parameter properties with `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`, so importing `@gaveta/core` crashes every CLI command. · Declare the fields on the class and assign them in the constructor body.
- 2026-10-22 · T1.7 · `for await` on an `opendir()` handle throws `Directory handle was closed` while walking nested directories. · Read with `dir.read()` in a loop and `close()` in `finally`.
- 2026-10-22 · T1.7 · `node:sqlite` leaves double-quoted string literals off, and FTS5 treats `-` as NOT. · Quote the tokenizer as `'unicode61 remove_diacritics 2'`. A garbage file makes `PRAGMA quick_check` throw `SQLITE_NOTADB` (26); treat that as a corrupt cache and rebuild it, and do not pass a raw hyphenated string to `fts MATCH`.
- 2026-10-22 · T1.11 · Indexed `[[wikilinks]]` are not graph edges; only canonical `data-g-to` rows and pending ghosts are. A backlink anchor inside `ul.tasks` (enlace-20) has a null section id, so its context comes from the note plain text. Shifting a 200-character window when the match sits near the start makes the slice longer than 200. · Build edges from canonical and pending rows only, fall back to note plain text when `sectionId` is null, and grow the snippet one character at a time inside the cap.
- 2026-10-22 · T1.4 · Re-serializing every valid note rewrites Prettier-wrapped anchors, so fixture HTML would not stay byte-stable. · Preserve the source when the walk finds no repair, the file is already house-formatted, and `validateNote` passes; canonicalize only when something changed.
- 2026-10-22 · T1.8 · Title and alias lookup has to use `foldMatchKey` (spaces kept), not `slugify`. · Query `title_folded` and `alias_folded` with a bound `?`. Wikilinks resolve by title or alias only; `resolveRef` is id, then path, then title. Existing `data-g-pending` anchors stay pending for T1.9.
- 2026-10-22 · T1.8 · parse5 attribute locations cover the whole attribute (`href="…"`), and `startTag.endOffset` sits just after `>`. · Replace only the quoted value. Insert a missing attribute before that `>`.
- 2026-10-22 · T1.19 · A raw `search` string is FTS5 syntax (`-` is NOT, an unclosed quote throws) and bm25 ranks a shorter hit above a longer one. · Quote the whole query as one phrase, doubling internal quotes, before `MATCH`. Assert that the sqlite note is first only when it is the only hit. `search` rebuilds an empty index; a populated one stays put until `reindex` (T1.20).
- 2026-10-22 · T1.9 · A typed options object makes `=== null` fail `no-unnecessary-condition`, and a stale `href` span does not include the space before it. · Narrow through `unknown`. When promoting, replace `data-g-pending` in place and eat the whitespace before a leftover `href`. Plan every read before the first `writeVaultText`; a symlink that leaves the vault fails at read, while a directory without write permission fails the atomic create so the batch can roll back.
- 2026-10-22 · T1.9 · CodeQL's bad tag filter flags `/<script>/g` in a test assertion, not only sanitizer replaces. · Count the tag with `indexOf`.
- 2026-10-22 · T1.14 · parse5 leaves a `<meta>` that follows `<article>` in the body, and `normalizeNote` only keeps meta it found in `<head>`, so an adopted id, tags, and aliases disappear and a new id is minted. · Read that metadata with `parseNote` on the source and copy it into the head before the second normalize.
- 2026-10-22 · MVP · `gaveta init` skipped `--vault`/`GAVETA_VAULT` because vault discovery was disabled for init. · Resolve the init target as positional > `--vault` > `GAVETA_VAULT` > cwd (`resolveInitDirectory`).
- 2026-10-22 · MVP · Node 22.14 on macOS can ship `node:sqlite` without FTS5 (`no such module: fts5`), which used to surface as `E_INDEX_CORRUPT`. · Engines `>=22.18.0`, probe FTS5 at startup (`E_RUNTIME_UNSUPPORTED`), and CI on 22.18.0.
- 2026-10-22 · MVP · ExperimentalWarnings for SQLite and type stripping print to stderr before `@gaveta/core` loads. · Install the warning filter in `packages/cli/bin/warning-filter.js` before importing the CLI.
- 2026-10-22 · T1.10 · `chmod 0444` on a note does not stop an atomic replace, because `rename` only needs write permission on the directory. · Make the destination directory mode `0555` so creating the temp file fails, then restore the notes that were already rewritten.
- 2026-10-22 · T1.15 · parse5 gives a fragment an implied `html`/`body` with no source location, so a section splice cannot use the body span. · Slice the `section` or `article` that actually occurs in the source; when the body location is missing, treat the input as a fragment. `--if-match` must be checked against the file bytes before any write, including `new`, or a conflict still creates the note.
- 2026-10-22 · fix · `runCli` resolves the vault before every command, and an explicit `--vault` or `GAVETA_VAULT` that does not exist yet turns into `E_VAULT_NOT_FOUND` even for `init`. · A command that creates the vault sets `skipsVaultDiscovery: true` on its `CommandSpec`.
