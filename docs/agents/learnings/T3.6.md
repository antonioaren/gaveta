# T3.6 learnings (REQ-APP-12)

Format: `YYYY-MM-DD · what went wrong · how it was fixed`

- 2026-10-26 · `wikilinkHtmlCompletionSource` returned a `Promise` as `CompletionResult.options`. CodeMirror expects either a synchronous `options` array or an async **completion source** (`Promise<CompletionResult | null>`). Passing a promise as `options` led to `options is not iterable`, so the autocomplete panel never opened and Linux e2e timed out waiting for `/api/wikilink-complete` when typing drove completion. · Make the source `async`, `await fetchWikilinkCompletions`, and return a normal `options` array.
- 2026-10-26 · `activateOnTyping` alone missed some edits (for example Playwright `insertText`). · Add `wikilinkHtmlAutocompleteTrigger` (`EditorView.updateListener` + `startCompletion` when the doc changes inside an open `[[`).
- 2026-10-26 · After `autoCloseTags`, markup such as `</p>` can sit between `[[` and the cursor; treating any `<`/`>` in the segment as “inside a tag” blocked completion. · In `wikilinkCompletionContextBefore`, use only the prefix before the first `<` or `>` as the query and replace range end.
- 2026-10-26 · CodeMirror lives in an open shadow root. Playwright clicks on pierced `.cm-content` do not run shadow `pointerdown` handlers; `keyboard.type` often never reaches the editor. Clicks on the `code-note-editor` host do fire host/shadow `pointerdown`. · On host and shadow `pointerdown`, call `view.focus()`. E2e: wait for code mode, click the host, use `insertText` for `[[`, assert the API response, then finish the link text (tooltip pick is covered by unit tests).
- 2026-10-26 · Merging `main` after other tasks landed conflicted in `VisualNoteEditor.tsx` (T3.13 merge UI vs wikilink menu). · Keep both `NoteMergeView` / `useExternalNoteRevision` and `WikilinkCompletionMenu`.
- 2026-10-26 · Code-mode e2e failed on macOS when a second `codeHost.click()` ran before typing the wikilink suffix: host `pointerdown` refocused CodeMirror with the caret at document start, so `insertText` prepended garbage before `<!doctype`. · E2e appends via `gaveta-code-append-at-end` after the API assertion; poll until `[[Form` / `[[Formas de enlace]]` appear in the editor surface.
- 2026-10-26 · macOS CI flakes on the same SHA: `CodeNoteEditor` recreated CodeMirror whenever `initialValue` changed (every `onChange` from the parent), so an append could run on a view that was destroyed or reset before the assertion. · Drop `initialValue` from the mount effect deps; remount only via `NoteCodeMode` `key` / `locale` / `notePath` / `readOnly`.
