# T3.6 wikilink menu position (visual editor)

Format: `YYYY-MM-DD · what went wrong · how it was fixed`

- 2026-10-26 · After moving menu layout to CSS variables, `useLayoutEffect` depended only on `coords`. Coords were set while `hits` was still empty (component returned `null`), so the list mounted later without re-running the effect; `--wikilink-menu-top/left` stayed at the CSS default `0`. · `useWikilinkMenuListRef` applies coords on ref mount and in a layout effect when `visible` (hits + coords) becomes true; unit test renders coords-first then hits; e2e asserts the list bounding box is below the editor surface, not at the viewport origin.
