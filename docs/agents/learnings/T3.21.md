# T3.21 learnings

- Phase 2 is shell-only: keep `@gaveta/core` theme tokens unchanged; layout/control refresh lives in `apps/web/src/styles/shell-chrome.css` plus React structure (`ShellTopbar`, `ui/*` primitives).
- `lucide-react` icons are shell-only (bundled); pair every icon control with `aria-label` / `title` via `IconButton`.
- Overflow menus hide former topbar actions — e2e must open `shell-settings-trigger` or `note-actions-menu-trigger` before `vault-import` / `note-action-*` test ids.
- `SearchPaletteProvider` owns Ctrl+K and palette open state; topbar search trigger calls `setOpen(true)`.
- Prefer `details`/`summary` for meta and connections sections instead of bordered cards.
