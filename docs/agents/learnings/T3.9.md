# T3.9 — Phase 3 gate round-trips

**Task:** T3.9 automated + manual gate (`docs/gates/fase-3.md`).

## Pitfall

Skipping `build:web` before manual gate checks is unsafe; use `pnpm gate:3` which only runs Vitest on `packages/core/src/gate/phase3-round-trip.test.ts` (no web build). Manual steps in `fase-3.md` still require `pnpm build:web` for the shell.

## Approach

- **Discovery:** walk every `fixtures/**/*.html` under vaults, showcase, and claude; add **gate-1** corpus by importing `fixtures/markdown` once per test run.
- **Pipeline:** `normalize` → visual (`noteHtmlToEditorJson` / `editorJsonToNoteHtml`) → `normalize` (code save) → second `normalize` (idempotent bytes).
- **Assert:** `phase3SemanticSnapshot` (metadata, sections, links, tasks, plain text). Malicious vault: extra forbidden-substring check on output.
- **Do not** edit `docs/TASKS.md` or `docs/agents/LEARNINGS.md` on gate PRs; use this file instead.
