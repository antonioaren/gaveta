# T4.7 command log writer (REQ-CLI-15 follow-up)

Format: `YYYY-MM-DD · what went wrong · how it was fixed`

- 2026-10-26 · `gaveta stats` read `.gaveta/log.jsonl` but nothing wrote it. · Opt-in via `commandLog.enabled` in `.gaveta/config.json`; `appendCommandLogEntry` in core appends JSONL with rotation; CLI `run.ts` records after each vault command (except `stats`) including duration and `new`-specific fields.
- 2026-10-26 · macOS/Linux e2e for other tasks showed that refocusing a shadow CodeMirror host resets the caret. · Not applicable here; command log never stores paths, titles, or note bodies—only command name, timestamp, ok, duration, and aggregate `new` metrics.
- 2026-10-26 · Log write failures must not fail the user command. · `appendCommandLogEntry` catches all errors and returns `false`; rotation uses `writeAtomic`, routine lines use `O_APPEND`.
